# LWR-CPA 方案 v1.0：LWR 引导的连续相位聚合

> **定位**：基于 MoM 失效诊断的物理一致性聚合器第一版  
> **原则**：不写 TCW/TVB/ATRA 等中间尝试，从 SimDiff-MoM 直接推导到 LWR-CPA  
> **目标**：零训练开销，可直接在现有采样上离线验证

---

## 一、问题起点：MoM 在交通流中的异常

### 1.1 SimDiff-MoM 的设计假设

SimDiff 提出 Median-of-Means (MoM) 聚合，其统计假设为：

- 扩散生成 K 条采样，其中存在**极端异常值**（outliers / heavy-tailed noise）
- 采样围绕某个"真值"对称分布，异常值偏离中心
- MoM 通过 block-median 机制筛选掉被污染的 block，保留"干净"的估计

在 ETTh1/Traffic/Electricity 等通用数据集上，MoM 的 MSE 低于 Simple Average，验证了上述假设成立。

### 1.2 交通流拥堵相的异常现象

在 Fujian-30 交通流数据集（15min 粒度）上，MoM 出现反直觉行为：

| 指标 | MoM (SimDiff) | Simple Mean | 物理真值 |
|------|--------------|-------------|---------|
| 整体 MAE | 0.2290 | 0.2288 | — |
| 拥堵相 MAE (CG_MAE) | 30.998 | 30.981 | — |
| 拥堵相 TPR | 0.453 | 0.453 | **0.473** |

**异常点**：
1. MoM 的 CG_MAE **高于** Simple Mean，说明 median 机制在拥堵相引入了额外误差
2. 拥堵相 TPR 仅 0.453，远低于物理真值 0.473，说明 MoM 不仅没保留趋势，反而系统性地压制了趋势信号
3. 整体 MAE 几乎无差异，说明问题被 70% 自由流样本稀释

### 1.3 核心问题

> **MoM 的统计假设（采样围绕单一真值对称分布，存在异常值）与交通流物理（激波传播导致多模态条件分布，无异常值只有不同相位）不匹配。**

## 二、数学诊断：MoM 隐含假设与交通流物理的冲突

### 2.1 MoM 的统计最优性条件

设 K 条采样为 {Y^(k)}，MoM 将其分为 B 个 block，每块 m 个采样，计算 block mean 后取 median。

MoM 优于 Simple Mean 的**充要条件**是：

**条件 A（非对称污染）**：存在少量采样被系统性偏差 b != 0 污染，其余采样无偏。

**条件 B（重尾噪声）**：采样分布的峰度 > 3，极端值概率高于正态分布。

**条件 C（单模态真值）**：所有"干净"采样的条件期望相同：E[Y^(clean)] = Y*。

### 2.2 交通流采样的实际结构

通过诊断分析（组内方差、组间离散度、中位数偏移热力图），交通流扩散采样呈现：

Y^(k) = mu_phi + eps^(k),  eps^(k) ~ N(0, sigma^2),  phi ~ Mixture

其中 mu_phi 不是单一真值，而是**由激波相位决定的条件均值**：

| 激波相位 | 条件均值偏移 | 物理意义 |
|---------|------------|---------|
| 激波上升沿 (Front) | mu_phi < Y* | 拥堵形成中，真值继续下降 |
| 激波下降沿 (Tail) | mu_phi > Y* | 拥堵消散中，真值继续回升 |
| 稳态 (Steady) | mu_phi = Y* | 自由流或拥堵稳态 |

**关键推论**：
- 采样之间无"好/坏"之分，只有**不同物理相位的实现**
- 不存在重尾异常值，所有采样都是同一条件分布的 i.i.d. 噪声
- MoM 的 median 在随机 block 中被迫选择"中间相位"，恰好抹平了激波结构

### 2.3 为什么 Simple Mean 反而更好

当采样为 i.i.d. 同分布时：

MSE(w) = sigma^2 ||w||^2,  s.t. sum_k w_k = 1

由 Cauchy-Schwarz，||w||^2 >= 1/K，等号当且仅当 w_k = 1/K。MoM 的隐式非均匀权重（median 的选择效应）必然增加方差。

> **结论**：在交通流当前采样结构下，Simple Mean 是 MSE 最优线性估计。MoM 的失效不是参数问题，而是**问题范式错误**——把物理相位问题当作统计异常值问题处理。

## 三、物理洞察：LWR 激波的「趋势-反转」二象性

### 3.1 真实 TPR = 0.473 的物理解释

从 ground truth 统计得到拥堵相真实 TPR = 0.473，意味着：

- **47% 样本**：历史趋势与未来趋势同向（激波上升沿/下降沿的延续段）
- **53% 样本**：历史趋势与未来趋势反向（激波峰值后的反转段）

这不是噪声，而是 LWR 激波传播的物理必然：

节点 A（激波上升沿）：历史 downtrend -> 未来 downtrend（趋势延续）
节点 B（激波下降沿）：历史 uptrend -> 未来 uptrend（趋势延续）
节点 C（激波峰值）：历史 uptrend -> 未来 downtrend（趋势反转）

在 15min 粒度下，同一拥堵事件的不同节点处于激波的不同相位。

### 3.2 MoM 如何抹平激波结构

MoM 的 median 操作等价于：

Y^MoM = median_b { (1/m) sum_{k in block_b} Y^(k) }

当采样来自混合相位分布时，median 选中的是"中间相位"的 block，既非上升沿也非下降沿，而是**激波峰值附近的饱和段**——恰好对应趋势反转点。这解释了为什么 TPR 被压制到 0.453（低于真实 0.473）。

> **核心洞察**：MoM 的 median 在交通流中不是筛选"异常值"，而是**系统性地选择激波峰值**（最保守、最 flat 的相位），导致趋势湮灭。

## 四、LWR-CPA 第一版：极简可验证方案

### 4.1 设计原则

1. **零训练**：不引入可学习参数，全部基于历史序列的解析计算
2. **单节点验证**：第一版暂不引入图结构/上下游信息，只验证核心假设
3. **连续相位**：用标量 phi in [-1, 1] 替代离散状态标签
4. **物理可解释**：phi 的每个极端都有明确的 LWR 激波意义

### 4.2 连续相位 phi 的定义

基于历史流量序列 X_n = [x_{n,1}, x_{n,2}, ..., x_{n,T}]（原始值域，不经 RevIN）：

**一阶差分（速度）**：
v_{n,t} = x_{n,t} - x_{n,t-1}

**二阶差分（加速度/曲率）**：
a_{n,t} = v_{n,t} - v_{n,t-1} = x_{n,t} - 2*x_{n,t-1} + x_{n,t-2}

**相位定义**：

phi_n = sign(a_{n,T}) * sigmoid( (|a_{n,T}| - mu_a^train) / (sigma_a^train) * beta )

其中：
- a_{n,T}：历史窗口最后一个时间步的二阶差分（当前"加速度"）
- mu_a^train, sigma_a^train：训练集上 |a_{n,T}| 的均值和标准差（一次性统计）
- beta：温度系数，控制相位敏感度（建议初值 beta = 2.0）
- sign(a_{n,T})：决定拥堵是"形成中"还是"消散中"

**物理意义**：

| a_{n,T} | phi_n | 物理状态 | 聚合策略 |
|----------|---------|---------|---------|
| 负且绝对值大 | -> +1 | 拥堵**形成中**（流量加速下降） | 选最悲观采样（min） |
| 正且绝对值大 | -> -1 | 拥堵**消散中**（流量加速回升） | 选最乐观采样（max） |
| 接近 0 | approx 0 | 稳态（自由流或拥堵稳态） | 均匀平均（mean） |

**为什么用二阶差分？**

- 一阶差分（斜率）只能区分"上升/下降"，无法区分"加速下降"（拥堵加剧）和"减速下降"（接近底部）
- 二阶差分（曲率）捕捉激波的核心特征：**激波是流量的突变，表现为加速度的极值**
- LWR 激波解在离散化后，激波面处二阶差分显著异于零

### 4.3 聚合公式

Y_n^CPA = (1 - |phi_n|) * uniform_mean + |phi_n| * Y_n^extreme(phi_n)

其中：
uniform_mean = (1/K) sum_{k=1}^K Y_n^(k)

极端选择项：
Y_n^extreme(phi_n) = min_k Y_n^(k)   if phi_n > 0  （拥堵形成，选最悲观）
Y_n^extreme(phi_n) = max_k Y_n^(k)   if phi_n < 0  （拥堵消散，选最乐观）

### 4.4 与 MoM 的本质区别

| 维度 | MoM | LWR-CPA v1 |
|------|-----|-----------|
| **选择依据** | 采样之间的统计排序（median） | 历史序列的二阶微分（物理相位） |
| **输出性质** | 离散选择（某个 block 的 mean） | 连续融合（|phi| 控制稳态/激波比例） |
| **物理意义** | 无 | phi 直接对应 LWR 激波的曲率 |
| **对 TPR 的影响** | 系统性压制到 ~0.45 | 形成期 -> 低预测（TPR 高），消散期 -> 高预测（TPR 高） |
| **对 CG_MAE 的影响** | 引入额外方差 | 在激波区域注入有益偏差，抵消方差 |

## 五、验证实验设计（本周可执行）

### 5.1 实验 1：phi 的物理有效性验证

**目的**：证明 phi 确实捕捉到了激波相位，而非随机噪声。

**方法**：
1. 在训练集上计算所有拥堵样本的 phi_n
2. 按 phi_n 分 5 个桶：[-1, -0.6), [-0.6, -0.2), [-0.2, 0.2), [0.2, 0.6), [0.6, 1]
3. 计算每桶的**真实 TPR**（ground truth 的趋势延续率）

**预期结果**：
- 桶 [-1, -0.6)（强消散相位）：TPR approx 0.85+（历史 uptrend，未来 uptrend 延续）
- 桶 [0.6, 1]（强形成相位）：TPR approx 0.85+（历史 downtrend，未来 downtrend 延续）
- 桶 [-0.2, 0.2]（稳态）：TPR approx 0.5（随机）

**如果预期成立**：说明 phi 成功分离了激波的不同相位，为聚合器提供了有效信号。

### 5.2 实验 2：LWR-CPA vs MoM vs Simple Mean

**目的**：验证 LWR-CPA 是否能降低 CG_MAE。

**对照组**：
1. **MoM**（SimDiff 原始）：K=10, B=5, m=2
2. **Simple Mean**：w_k = 1/K
3. **LWR-CPA v1**：beta = 2.0，基于原始值域二阶差分

**评估指标**：
- 整体 MAE
- 拥堵相 MAE (CG_MAE)
- 节假日-拥堵 MAE (HOL_CG)
- 拥堵相 TPR (TPR_CG)
- 自由流 MAE (FF_MAE，确保不劣化)

**成功标准**：
- CG_MAE < 30.981（击败 Simple Mean）
- HOL_CG 显著下降（节假日是激波最活跃时段）
- FF_MAE 不劣化（phi approx 0 时退化为 Simple Mean）

### 5.3 实验 3：beta 敏感性分析

**目的**：找到最优温度系数。

**方法**：测试 beta in {0.5, 1.0, 2.0, 3.0, 5.0}，记录 CG_MAE 和 TPR_CG。

**预期**：
- beta 过小（0.5）：phi 过于平缓，接近 Simple Mean
- beta 过大（5.0）：phi 过于尖锐，边界跳变
- 最优 beta 应在 1.0-3.0 之间

### 5.4 实验 4：消融分析——一阶 vs 二阶差分

**目的**：证明二阶差分（曲率）优于简单斜率。

**对照组**：
- **LWR-CPA-v1**：基于 a_{n,T}（二阶差分）
- **LWR-CPA-slope**：基于 v_{n,T}（一阶差分，仅 sign 无曲率信息）

**预期**：二阶差分版的 CG_MAE 显著低于一阶差分版。

## 六、论文叙事线（基于 MoM 推导，不提中间尝试）

### Paragraph 1：现象与反直觉发现

> SimDiff 在通用时序数据集上验证了 MoM 的有效性，其核心假设是扩散采样中存在极端异常值。然而，在交通流拥堵相中，我们观察到反直觉现象：MoM 的 CG_MAE 高于 Simple Mean，且拥堵相 TPR 被系统性压制至 0.453（低于物理真值 0.473）。这表明 MoM 的统计假设在交通流物理中失效。

### Paragraph 2：数学根因分析

> 通过采样结构诊断，我们发现交通流扩散采样不满足 MoM 的充要条件：采样之间不存在"好/坏"的异常值分化，而是围绕由激波相位决定的条件均值 i.i.d. 分布。在此结构下，Simple Mean 是 MSE 最优线性估计，MoM 的隐式非均匀权重必然引入额外方差。

### Paragraph 3：物理洞察——LWR 激波二象性

> 真实拥堵相 TPR = 0.473 揭示了 LWR 激波的本质：拥堵不是简单的趋势延续，而是包含形成（上升沿）、峰值（饱和）、消散（下降沿）的连续过程。MoM 的 median 操作系统性地选择激波峰值附近的饱和段，导致趋势湮灭。

### Paragraph 4：LWR-CPA 方案

> 我们提出 LWR-guided Continuous Phase Aggregation (LWR-CPA)，用历史流量的二阶差分（曲率）估计激波相位 phi in [-1, 1]，并在聚合中软融合稳态均值与激波边缘选择。phi 的物理意义明确：正相位对应拥堵形成（选悲观边缘），负相位对应拥堵消散（选乐观边缘），零相位退化为均匀平均。

## 七、风险与备选

| 风险 | 判断标准 | 备选方案 |
|------|---------|---------|
| phi 与 TPR 分桶关系不显著 | 实验 1 中各桶 TPR 差异 < 0.1 | 说明二阶差分不足以捕捉相位，需引入空间信息（上下游邻居状态）或三阶差分 |
| CG_MAE 仍无法低于 Simple Mean | 实验 2 中 CG_MAE > 30.981 | 说明即使相位识别正确，当前采样在边缘处覆盖不足，需转向生成器引导（Guidance）产生更分散的采样 |
| beta 敏感度过高 | 不同 beta 导致 CG_MAE 波动 > 1.0 | 引入自适应 beta 校准，或改用 tanh 替代 sigmoid |
| 自由流 MAE 劣化 | FF_MAE 上升 > 2% | 添加自由流保护机制：当 |a_{n,T}| < epsilon_FF 时强制 phi_n = 0 |
