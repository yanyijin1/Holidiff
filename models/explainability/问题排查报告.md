# 可解释性问题排查报告

## 问题描述

训练 15 epoch 后，物理参数 `v_critical` 和 `alpha` 未发生变化，始终保持初始化值：
- `v_critical = 30.0`
- `alpha = 0.7`

## 根本原因

### 陷阱 1：v_critical 不是 nn.Parameter（致命）

原始代码：
```python
class PhysicsComputedGraphKernel(nn.Module):
    def __init__(self, ..., v_critical=30.0):
        self.v_critical = v_critical  # ← 这是一个 Python float！
```

**问题**：
- `self.v_critical = 30.0` 不是 `nn.Parameter`
- `model.parameters()` 遍历不到它
- 优化器根本不知道它的存在

### 陷阱 2：> 操作不可导（更致命）

原始代码：
```python
regime = (v_clipped > self.v_critical).float()
```

**问题**：
- `>` 是布尔比较，梯度恒为 0
- 无论 `v_critical` 怎么变，loss 对它的梯度都是 0
- 优化器拿到 `grad=0`，永远不会更新

### alpha 为什么也不变？

alpha 是 `nn.Parameter`，理论上可学习，但 15 epoch 不变的可能原因：

| 原因 | 验证方法 | 概率 |
|------|----------|------|
| 梯度太小 | 打印 `p.grad.abs().mean()` | 高 |
| 初始值已接近最优 | 看 A_kernel 和 A_adp 哪个主导 | 中 |
| 学习率太低 | 对比其他参数的变化幅度 | 中 |

## 快速验证方法

在训练循环中，`loss.backward()` 之后插入：

```python
for name, p in model.named_parameters():
    if 'v_critical' in name or 'alpha' in name:
        grad = p.grad
        print(f"[PARAM] {name}: value={p.item():.4f}, grad={grad.item() if grad is not None else 'None'}")
```

**预期结果**：
- `alpha`：grad 应该有值（哪怕很小），说明可学习
- `v_critical`：根本搜不到这个参数，因为它不是 `nn.Parameter`

## 修复方案

### 修复 v_critical

```python
class PhysicsComputedGraphKernel(nn.Module):
    def __init__(self, d_model, num_nodes, v_critical_init=30.0):
        super().__init__()
        
        # 陷阱1修复：改成 nn.Parameter
        self.v_critical = nn.Parameter(torch.tensor(v_critical_init, dtype=torch.float32))
        
        self.num_nodes = num_nodes
```

### 修复不可导问题

```python
def compute_regime(self, v_obs):
    # 陷阱2修复：用 sigmoid 代替硬阈值
    v_clipped = torch.clamp(v_obs, 0, 150)
    temperature = 10.0  # 锐度系数，越大越接近硬阈值
    regime = torch.sigmoid((v_clipped - self.v_critical) * temperature)
    return regime.mean(dim=-1, keepdim=True)  # (B, N, 1)
```

**物理意义**：
- `v_critical` 附近是平滑过渡区，而不是硬截断
- 温度系数 10 意味着：
  - `v = v_critical + 0.5` → `regime ≈ 0.99`
  - `v = v_critical - 0.5` → `regime ≈ 0.01`
- 基本保持"阈值"的物理直觉，但可导了

### 完整修复后的 PCGK

```python
class PhysicsComputedGraphKernel(nn.Module):
    def __init__(self, d_model, num_nodes, v_critical_init=30.0):
        super().__init__()
        
        # 陷阱1修复：改成 nn.Parameter
        self.v_critical = nn.Parameter(torch.tensor(v_critical_init, dtype=torch.float32))
        
        # alpha 用 raw 参数 + sigmoid 保证 (0, 1)
        self.raw_alpha = nn.Parameter(torch.tensor(0.7))
        
        self.num_nodes = num_nodes
        
    @property
    def alpha(self):
        return torch.sigmoid(self.raw_alpha)
    
    def compute_regime(self, v_obs):
        # 陷阱2修复：用 sigmoid 代替硬阈值
        v_clipped = torch.clamp(v_obs, 0, 150)
        temperature = 10.0
        regime = torch.sigmoid((v_clipped - self.v_critical) * temperature)
        return regime.mean(dim=-1, keepdim=True)
```

## 验证修复效果

改完后，重新训练 1-2 个 epoch，检查：

```python
# 每个 epoch 结束打印：
for name, p in model.named_parameters():
    if 'v_critical' in name or 'raw_alpha' in name:
        print(f"[Epoch {epoch}] {name}: {p.item():.4f}")
```

**预期**：
- `v_critical`：从 30.0 开始，可能降到 25~35（取决于数据集）
- `raw_alpha`：从 0.7 开始，可能微调到 0.6~0.8

如果 1 个 epoch 后 `v_critical` 变了（哪怕只变 0.1），说明修复成功。

## 为什么 15 epoch 收敛但物理参数没变？

因为 SimDiff 的收敛是整体损失下降（pred 接近 target），但物理参数的变化对损失的边际贡献很小：

```
v_critical 偏移 5 km/h 
  → regime 变化 5% 
  → A_kernel 微调 
  → pred 变化 0.1% 
  → loss 变化极小
```

优化器在梯度下降时，优先更新对 loss 影响大的参数（W_q, W_k 等），物理参数被"淹没"了。

## 进阶优化：单独设置物理参数学习率

如果物理参数变化太慢，可以给物理参数单独设一个更大的学习率：

```python
# 单独设置物理参数的学习率
physics_params = []
other_params = []
for name, p in model.named_parameters():
    if 'v_critical' in name or 'alpha' in name or 'raw_alpha' in name:
        physics_params.append(p)
    else:
        other_params.append(p)

optimizer = torch.optim.Adam([
    {'params': other_params, 'lr': 1e-4},      # 普通参数
    {'params': physics_params, 'lr': 1e-3},     # 物理参数 10x 学习率
])
```

## 一句话总结

> 先修复 `v_critical` 的 `nn.Parameter` + `sigmoid` 阈值，确认它能动。然后观察 5-10 epoch 的变化。如果变化太慢，给物理参数单独设一个更大的学习率（比如 `1e-3`，而其他参数 `1e-4`）。
