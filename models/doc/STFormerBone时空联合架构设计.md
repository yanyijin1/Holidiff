## 一、核心创新：时空纠缠层 (ST-Layer)

### 1.1 物理动机：无距离的拓扑 LWR

**问题**：没有路段长度 $\Delta x$ 或自由流速度 $v_f$，只有拓扑信息（谁是谁的上游）。

**定义有向图** $\mathcal{G} = (\mathcal{V}, \mathcal{E})$：
- 节点 $i$：交通传感器
- 边 $(j \to i)$：当且仅当 $j$ 是 $i$ 的直接上游

**LWR 退化为拓扑守恒形式**：

$$\rho_i^{t+1} = \rho_i^t + \sum_{j \in \mathcal{U}(i)} (q_{j \to i}^t - q_{i \to k}^t)$$

**D 矩阵的物理意义**：

$$\mathbf{D} = \mathbf{I} - \mathbf{S}^T, \quad \mathbf{S}^T_{ij} = \begin{cases} 1 & \text{if } j \in \mathcal{U}(i) \\ 0 & \text{otherwise} \end{cases}$$

$\mathbf{D}\mathbf{q}$ 计算每个节点的**上游 deficit**——拥堵波沿拓扑边上行传播。

### 1.2 微观-宏观分解

| 分支 | 物理意义 | 实现 |
|------|----------|------|
| **时序分支** $\mathbf{H}_T$ | 微观随机性：司机换道、信号抖动、个体加速度 | RotaryAttn（无因果掩码） |
| **空间分支** $\mathbf{H}_S$ | 宏观传播：拥堵波沿拓扑边上游传播 | $\mathbf{D} @ \mathbf{Q}$（LWR） |

### 1.3 向量级门控

$$\mathbf{g} = \sigma(\mathbf{W}_g \cdot \text{Concat}[\mathbf{H}_T, \mathbf{H}_S])$$

$$\mathbf{H}^{(l+1)} = \mathbf{H}^{(l)} + \mathbf{g} \odot \mathbf{H}_T + (1-\mathbf{g}) \odot \mathbf{H}_S$$

**物理诠释**：
- $\mathbf{g} \to 1$：节点处于**自由流**，微观随机性主导
- $\mathbf{g} \to 0$：节点处于**拥堵传播**，宏观 LWR 主导
- 向量级门控：每个特征维度独立决定"微/宏"属性

## 二、架构对比

### 2.1 FormerBone vs STFormerBone

```
FormerBone (Sequential - 事后修正)：
┌──────────────────────────────────────────────────────────────┐
│ T-Down × 3 ─► T-Mid ─► T-Up × 3 ─► [S-LWR] ─► T-Fusion    │
│       时序编码固化                    ↑                       │
│                               空间修正是"事后打补丁"           │
└──────────────────────────────────────────────────────────────┘

STFormerBone (Joint - 内生耦合)：
┌──────────────────────────────────────────────────────────────────────────────┐
│ Input ─► ST-Layer₁ ─► ST-Layer₂ ─► ... ─► ST-Layerₙ ─► Output            │
│           ↕              ↕                        ↕                          │
│        时空纠缠         时空纠缠                时空纠缠  ← n 可调(默认3)   │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 数学对比

| | FormerBone | STFormerBone |
|---|---|---|
| **数学形式** | $\mathbf{H} = f_{\text{up}}(f_{\text{mid}}(f_{\text{down}}(\mathbf{X})))$ | $\mathbf{H}^{(l+1)} = \mathbf{H}^{(l)} + \mathbf{g} \odot \mathcal{T}(\mathbf{H}^{(l)}) + (1-\mathbf{g}) \odot \mathcal{S}(\mathbf{H}^{(l)}; \mathbf{D})$ |
| **空间注入** | 最后单层 | 每层同时 |
| **信息论** | $I(\mathbf{H}^{\text{mid}}; \mathcal{G}) \approx 0$ | $I(\mathbf{H}^{(l+1)}; \mathcal{G}) > I(\mathbf{H}^{(l)}; \mathcal{G})$ |

## 三、SimDiff 核心遗产（保留）

| 遗产 | 作用 | 实现位置 |
|------|------|----------|
| **NI (Normalization Independence)** | 训练/测试分布不一致时无偏估计 | Model 层：`(μ_Y, σ_Y)` 分离标准化 |
| **MoM (Median of Means)** | 对抗多模态分布的异常值 | `DiffusionAggregator.aggregate` |
| **DPM-Solver** | 20 步快速采样 | `DPMSolverSampler` |
| **No Skip** | 避免 U-Net skip 破坏扩散分布 | 移除所有跳跃连接 |


## 八、结论

STFormerBone 是**首个将 LWR 交通流守恒律嵌入扩散每层**的架构：

1. **空间建模**：通过 $\mathbf{D} = \mathbf{I} - \mathbf{S}^T$ 实现纯拓扑 LWR 传播（无距离信息）
2. **时间建模**：通过 RotaryAttn 捕捉微观随机扰动
3. **联合机制**：通过向量级门控 $\mathbf{g} \in \mathbb{R}^d$ 动态平衡微/宏观贡献
4. **扩散兼容**：严格残差 + Pre-LN + No Skip，完美适配 DPM-Solver 和 NI/MoM

**核心洞察**：拥堵传播不是"事后修正"，而是每层都参与的内生约束。

### 9.5 核心差异总结

| 特性 | FormerBone | STFormerBone |
|------|------------|--------------|
| **空间注入时机** | 最后单层 | 每层同时 |
| **时序注入时机** | 最后单层 | 每层同时 |
| **Skip Connection** | 有 | **无 (No Skip)** |
| **因果掩码** | Rotary 旋转 | **无掩码** |
| **时间注入方式** | 拼接 `Concat[t, h]` | 加法 `h + embed` |
| **物理先验** | 软约束 | **硬约束 (D 每层)** |
| **时空耦合** | 事后 | **内生** |
