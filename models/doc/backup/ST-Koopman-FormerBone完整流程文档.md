# STFormerBone 时空联合扩散预测架构

## 1. 架构概述

STFormerBone 是一个时空联合的扩散预测模型，将时序特征提取和空间图传播统一在每层的联合处理中。

### 核心设计理念

```
FormerBone (分离式)                    STFormerBone (联合式)
┌────────────────────┐                ┌────────────────────┐
│ T-Down × 3 (时序)   │                │                    │
│       ↓             │                │  ST-Layer × n      │
│ T-Mid × 1 (瓶颈)    │                │  ┌───────────────┐ │
│       ↓             │                │  │ Temporal: QKV │ │
│ T-Up × 3 (Concat)   │                │  │     ↓         │ │
│       ↓             │                │  │ Spatial: D@Q  │ │
│ S-LWR × 1 (空间)    │ ← 断裂点!      │  │     ↓         │ │
│       ↓             │                │  │ Gate: Vec×n   │ │
│ T-Fusion × 1        │                │  │     ↓         │ │
└────────────────────┘                │  │ Residual       │ │
                                      │  └───────────────┘ │
                                      └────────────────────┘
```

### 关键创新点

1. **时空联合处理**: 每层同时处理时序和空间信息，避免信息断裂
2. **向量级门控**: 每维度独立决定时序/空间特征的贡献权重
3. **无因果掩码**: 纯扩散模式，全局注意力机制
4. **D@Q 拓扑传播**: 基于图结构的LWR物理先验

│  # 展平                                                                       │
│  x_flat = x_norm.reshape(B*N, pred_len)       # (B*N, 12)                     │

    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐

│────────────────────────────────────────────────────────────────────────────────│

│  # 随机时间步                                                                   │
│  t = randint(0, T) 形状 (B*N,)                                                 │
│                                                                                │
│  # 加噪                                                                        │
│  x_k = sqrt(alpha_t) * x_flat + sqrt(1-alpha_t) * noise                       │
│                                                                                │
│  # x_k 形状: (B*N, 12)                                                         │
│                                                                                │

│  │──────────────────────────────────────────────────────────────────────────│  │

│  │   cond = cond_flat.reshape(B, N, seq_len) # (B, N, 96)                    │  │
│  │   t = t.reshape(B, N, 1)                # (B, N, 1)                     │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │

│  └──────────────────────────────────────────────────────────────────────────┘  │

## 4. 核心模块说明

### 4.1 STJointLayer (时空联合层)

```python
class STJointLayer(nn.Module):
    """
    时空联合层
    
    整合时序分支 + 空间分支 + 向量级门控
    
    输入: (B, N, P, d)
    输出: (B, N, P, d)
    """
```

**数学形式**:
```
gate = σ(W_g · Concat[H_T, H_S])
H_new = H + gate ⊗ H_T + (1-gate) ⊗ H_S
```

### 4.2 TemporalAttention (时序分支)

```python
class TemporalAttention(nn.Module):
    """
    时序注意力分支
    
    架构：Pre-LN → RotaryAttn → FFN → Residual
    
    特点：
    - 无因果掩码（纯扩散，注意力全局）
    - Pre-LN 结构（更稳定）
    - RotaryEmbedding（位置编码）
    """
```

### 4.3 SpatialPropagation (空间分支)

```python
class SpatialPropagation(nn.Module):
    """
    空间传播分支
    
    核心：D @ Q 操作（LWR 物理先验）
    
    D 矩阵物理意义：
    - D = I - S^T
    - S^T: 下游传播权重（上游客流流向）
    - D @ q: 上游 deficit（拥堵波沿拓扑边上行传播）
    """
```

## 6. 与 FormerBone 对比

| 特性 | FormerBone | STFormerBone |
|------|-----------|--------------|
| 时空处理 | 分离式 | 联合式 |
| 编码器结构 | T-Down/T-Mid/T-Up | 无 (纯联合) |
| Skip Connection | 有 | 无 |
| 因果掩码 | 有 | 无 |
| S-LWR 位置 | 末尾单次 | 每层执行 |

## 7. 核心优势

1. **时空耦合内生化**: 每层同时处理时空信息，避免信息断裂
2. **向量级门控**: 细粒度控制每维度特征来源
3. **架构简化**: 移除复杂的编解码器结构
4. **扩散友好**: 无因果掩码，适合扩散模型特性

## 8. ST-Koopman-FormerBone：时空Koopman联合扩散架构（最终版）

### 8.1 核心设计决策确认

| # | 设计点 | 选择 | 具体实现 |
|---|--------|------|----------|
| 1 | K矩阵来源 | **C (初始化EDMD+微调)** | `nn.Parameter(K_edmd, requires_grad=True)`，lr=0.01×base |
| 2 | ψ升维映射 | **B (两层MLP)** | `Linear→GELU→Linear` |
| 3 | λ稳定性 | **C (固定值)** | 物理常数，不参与梯度更新 |
| 4 | 模态数K | **分层 K=[2,2,3]** | Layer 1-2用2模态，Layer 3用3模态 |
| 5 | Patch实现 | **B (动态P)** | `P = pred_len // 6`，动态切片对齐 |

### 8.2 物理意义

| Layer | λ值 | 物理对应 | 负责现象 |
|-------|-----|----------|----------|
| **Layer 1** | [0.5, 0.3] | 快速衰减模态 | 拥堵形成/消散的瞬态动力学（5-15分钟） |
| **Layer 2** | [0.9, 0.3] | 中速衰减模态 | 同步流亚稳态过渡（15-45分钟） |
| **Layer 3** | [0.9, 0.3, 0.99] | 慢速衰减+日周期 | 早晚高峰转换、跨天周期（45分钟-3小时） |

### 8.4 关键设计决策

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 三分支 vs 双分支
   ─────────────────
   双分支: [Local, Space] ──► 仅捕捉局部+拓扑，长程依赖隐式学习（弱）
   三分支: [Local, Koopman, Space] ──► 显式建模全局模态演化（强），长程物理一致

2. Koopman分层 (Layer-wise λ)
   ─────────────────────────────
   Layer 1: λ=[0.5, 0.3]      ──► 快速衰减，短时记忆（拥堵形成）
   Layer 2: λ=[0.9, 0.3]      ──► 中速衰减，过渡模态（同步流）
   Layer 3: λ=[0.9, 0.3, 0.99] ──► 慢速衰减+日周期（长程关键）

   物理意义: 浅层快速响应扰动，深层保持长期趋势

3. 12步 vs 36步 自适应
   ─────────────────────
   12步: 仅使用 Layer 1-2 (λ≤0.9)，Layer 3 日周期分支通过门控 g_koop→0 自动关闭
   36步: 三层全开，Layer 3 的 λ=0.99 日周期模态激活，提供跨高峰记忆

4. 空间高阶传播 (D^k)
   ───────────────────
   12步: D¹ (直接邻居) 足够
   36步: 通过层级堆叠实现 D³ 效应（3跳传播），拥堵波覆盖全路网

5. 残差连接 (No Skip)
   ───────────────────
   h_out = h + Σ(gᵢ·hᵢ)  ◄── 严格残差，无U-Net跳跃，保持扩散马尔可夫性

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| **门控维度** | 2维 | 3维 |
| **物理一致性** | 中 (仅空间LWR) | 高 (时空联合物理) |

#### 8.7.3 Koopman分支数学细节

**升维映射 ψ**:
```
ψ(h) = W₂ · GELU(W₁ · h)

W₁: (d, d*2)  = (128, 256)
W₂: (d*2, d*K) = (256, 128*3) = (256, 384)  # K=3时
```

**Koopman模态演化**:
```
h_modes = K · ψ(h)  # K = diag(λ₁, λ₂, ..., λ_K)
h_koop = W_koop · h_modes  # W_koop: (d*K, d)
```

**门控融合**:
```
g_concat = concat([h_local, h_koop, h_spatial], dim=-1)  # (B,N,P,3d)
g = softmax(W_gate · g_concat)  # (B,N,P,3)

h_out = h + g[:,:,:,0:1] * h_local + g[:,:,:,1:2] * h_koop + g[:,:,:,2:3] * h_spatial
```

#### 8.8.2 KoopmanBranch 实现

```python
class KoopmanBranch(nn.Module):
    def __init__(self, d_model, n_modes, koopman_lr_scale=0.01):
        super().__init__()
        self.n_modes = n_modes
        
        # ψ升维: 两层MLP
        self.psi_proj = nn.Sequential(
            nn.Linear(d_model, d_model * 2),
            nn.GELU(),
            nn.Linear(d_model * 2, d_model * n_modes)
        )
        
        # K矩阵: 初始化EDMD + 微调
        K_init = self.compute_edmd_init(n_modes)  # 离线EDMD
        self.K = nn.Parameter(K_init, requires_grad=True)
        
        # 重构投影
        self.W_koop = nn.Linear(d_model * n_modes, d_model)
        
    def forward(self, h):
        # ψ升维
        psi_h = self.psi_proj(h)  # (B,N,P,d*n_modes)
        
        # 模态衰减: K · ψ(h)
        B, N, P, _ = psi_h.shape
        psi_h = psi_h.view(B, N, P, self.n_modes, -1)
        koop_modes = self.K.unsqueeze(0).unsqueeze(0).unsqueeze(0) * psi_h  # 广播乘法
        koop_modes = koop_modes.reshape(B, N, P, -1)
        
        # 重构
        h_koop = self.W_koop(koop_modes)
        return h_koop
```

#### 8.8.4 动态Patch选择

```python
def forward(self, x_k, t, cond, pred_len=12):
    # 动态P
    P_pred = pred_len // 6  # 12步→P=2, 36步→P=6
    P_cond = cond.shape[-1] // 6  # 固定16
    
    # Patch对齐
    cond_patches = cond.unfold(-1, 6, 6)[:, :, -P_pred:, :]  # 取最后P_pred个
    x_patches = x_k.unfold(-1, 6, 6)
    
    # Concat + 投影
    patches = torch.cat([cond_patches, x_patches], dim=-2)
    h = self.input_proj(patches)
    
    return h
```

#### 8.9.2 误差界

$$
\|\mathbf{x}_t - \mathbf{x}_t^{\text{true}}\| \leq \underbrace{C_1 \Delta t}_{\text{离散误差}} + \underbrace{C_2 \epsilon_{\text{Koopman}}}_{\text{模态近似误差}} + \underbrace{C_3 \sigma_{\text{micro}}^2}_{\text{微观噪声}}
$$

其中：
- $\Delta t$: 扩散步长（DPM-Solver控制）
- $\epsilon_{\text{Koopman}}$: EDMD截断误差
- $\sigma_{\text{micro}}^2$: 不可约微观随机性
