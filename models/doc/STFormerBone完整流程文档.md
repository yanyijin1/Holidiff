# STFormerBone 时空联合扩散预测架构

## 1. 架构概述

STFormerBone 是一个时空联合的扩散预测模型，将时序特征提取和空间图传播统一在每层的联合处理中。

### 核心设计理念

```
FormerBone (分离式)                    STFormerBone (联合式)
┌────────────────────┐                ┌────────────────────┐
│ T-Down × 3 (时序)   │                │                    │
│       ↓             │                │  ST-Layer × n      │
│ T-Mid × 1 (瓶颈)    │                │  ┌───────────────┐ │
│       ↓             │                │  │ Temporal: QKV │ │
│ T-Up × 3 (Concat)   │                │  │     ↓         │ │
│       ↓             │                │  │ Spatial: D@Q  │ │
│ S-LWR × 1 (空间)    │ ← 断裂点!      │  │     ↓         │ │
│       ↓             │                │  │ Gate: Vec×n   │ │
│ T-Fusion × 1        │                │  │     ↓         │ │
└────────────────────┘                │  │ Residual       │ │
                                      │  └───────────────┘ │
                                      └────────────────────┘
```

### 关键创新点

1. **时空联合处理**: 每层同时处理时序和空间信息，避免信息断裂
2. **向量级门控**: 每维度独立决定时序/空间特征的贡献权重
3. **无因果掩码**: 纯扩散模式，全局注意力机制
4. **D@Q 拓扑传播**: 基于图结构的LWR物理先验

## 2. 完整训练流程

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                              训练流程 (forward_train)                           │
└────────────────────────────────────────────────────────────────────────────────┘

【输入】
  batch_x: (B, L=96, N=30)         # 历史序列
  batch_y: (B, L+48+12, N=30)      # 完整标签

    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 1: 数据准备 & NI 归一化                                                    │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  # 提取目标部分                                                                 │
│  x_target = batch_y[:, -pred_len:, :]  # (B, 12, N)                          │
│                                                                                │
│  # 条件序列：用 RevIN 归一化                                                     │
│  cond_ts = RevIN_norm(batch_x)              # (B, N, L)                      │
│                                                                                │
│  # 目标序列：用自身统计量归一化（NI）                                             │
│  x = x_target.permute(0, 2, 1)                # (B, N, 12)                   │
│  mean_Y = mean(x, dim=1)                       # (B, 1, N)                     │
│  std_Y = 1 (固定)                              # std_Y = 1                    │
│  x_norm = (x - mean_Y) / (std_Y + ε)           # (B, N, 12)                  │
│                                                                                │
│  # 展平                                                                       │
│  x_flat = x_norm.reshape(B*N, pred_len)       # (B*N, 12)                     │
│  cond_flat = cond_ts.reshape(B*N, seq_len)   # (B*N, 96)                     │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 2: 扩散加噪                                                                │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  # 随机时间步                                                                   │
│  t = randint(0, T) 形状 (B*N,)                                                 │
│                                                                                │
│  # 加噪                                                                        │
│  x_k = sqrt(alpha_t) * x_flat + sqrt(1-alpha_t) * noise                       │
│                                                                                │
│  # x_k 形状: (B*N, 12)                                                         │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 3: STFormerBone 前向                                                       │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  输入: x_k (B*N, 12), t (B*N,), cond_flat (B*N, 96)                           │
│                                                                                │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 3.1 Rearrange: (B*N, T) → (B, N, T)                                      │  │
│  │──────────────────────────────────────────────────────────────────────────│  │
│  │   x = x_k.reshape(B, N, pred_len)       # (B, N, 12)                     │  │
│  │   cond = cond_flat.reshape(B, N, seq_len) # (B, N, 96)                    │  │
│  │   t = t.reshape(B, N, 1)                # (B, N, 1)                     │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 3.2 Patch Embed (unfold + Linear)                                        │  │
│  │──────────────────────────────────────────────────────────────────────────│  │
│  │   # unfold: (B,N,L) → (B,N,P,patch_len)                                   │  │
│  │   cond_patches = cond.unfold(-1, patch_len=6, stride=6)  # (B,N,P_cond,6)│  │
│  │   x_patches = x_k.unfold(-1, patch_len=6, stride=6)      # (B,N,P_x,6)   │  │
│  │                                                                              │  │
│  │   # concat: cond + x                                                      │  │
│  │   patches = concat([cond_patches, x_patches], dim=-2) # (B,N,P,6)         │  │
│  │                                                                              │  │
│  │   # Linear 投影                                                           │  │
│  │   h = W_input_projection(patches)                   # (B,N,P,d=128)      │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 3.3 时间步嵌入 & 加法注入                                                   │  │
│  │──────────────────────────────────────────────────────────────────────────│  │
│  │   t_embed = time_embed(t)                           # (B,N,1,d)           │  │
│  │   h = h + t_embed                                   # (B,N,P,d) 广播加法  │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 3.4 ST-Layer × configs.st_layers (时空联合处理) ← 核心                   │  │
│  │──────────────────────────────────────────────────────────────────────────│  │
│  │                                                                              │  │
│  │   for layer in st_layers (3次):                                            │  │
│  │   ┌────────────────────────────────────────────────────────────────────┐ │  │
│  │   │  输入: h (B,N,P,d)                                                  │ │  │
│  │   │                                                                       │ │  │
│  │   │  ┌─────────────────────────────────────────────────────────────────┐│ │  │
│  │   │  │ Pre-LayerNorm                                                   ││ │  │
│  │   │  │ (可选: 本实现省略以简化)                                          ││ │  │
│  │   │  └─────────────────────────────────────────────────────────────────┘│ │  │
│  │   │         │                                                             │ │  │
│  │   │         ├──────────────────────┬────────────────────────────────────┤ │  │
│  │   │         ▼                      ▼                                     │ │  │
│  │   │  ┌─────────────────┐    ┌─────────────────┐                         │ │  │
│  │   │  │ 时序分支        │    │ 空间分支        │                         │ │  │
│  │   │  │                 │    │                 │                         │ │  │
│  │   │  │ RotaryAttn      │    │ q = W_q(h)      │                         │ │  │
│  │   │  │ (无因果掩码)    │    │ q_s = D @ q     │ ← D=拓扑LWR算子         │ │  │
│  │   │  │                 │    │ h_s = W_upd(q_s)│                         │ │  │
│  │   │  │ h_t            │    │ h_s             │                         │ │  │
│  │   │  └─────────────────┘    └─────────────────┘                         │ │  │
│  │   │         │                      │                                     │ │  │
│  │   │         └──────────┬───────────┘                                     │ │  │
│  │   │                    ▼                                               │ │  │
│  │   │           ┌─────────────────────────────────┐                      │ │  │
│  │   │           │ 向量门控融合                      │                      │ │  │
│  │   │           │ gate = σ(W_g·Concat[h_t,h_s])   │                      │ │  │
│  │   │           │ h = h + gate*h_t + (1-gate)*h_s │  ← 严格残差           │ │  │
│  │   │           └─────────────────────────────────┘                      │ │  │
│  │   │                   │                                                │ │  │
│  │   │  输出: h (B,N,P,d)                                                │ │  │
│  │   └────────────────────────────────────────────────────────────────────┘ │  │
│  │                                                                              │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 3.5 输出投影 & reshape                                                   │  │
│  │──────────────────────────────────────────────────────────────────────────│  │
│  │   # 只取预测部分的 patch                                                 │  │
│  │   h_out = h[:, :, -P_x:, :]                      # (B, N, P_x, d)       │  │
│  │                                                                              │  │
│  │   # 展平 + 线性投影                                                       │  │
│  │   h_flat = h_out.reshape(B, N, -1)                 # (B, N, P_x*d)        │  │
│  │   pred_flat = W_outs(h_flat)                        # (B*N, pred_len)    │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  输出: pred_flat (B*N, 12)  ← 归一化空间的预测                                   │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 4: 反归一化 & 损失计算                                                     │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  # Reshape                                                                   │
│  pred = pred_flat.reshape(B, N, pred_len)  # (B, N, 12)                       │
│  pred = pred.permute(0, 2, 1)              # (B, 12, N)                       │
│                                                                                │
│  # RevIN 反归一化（NI: 用训练集的 affine 参数）                                 │
│  pred_denorm = RevIN_denorm(pred)          # (B, 12, N)                       │
│                                                                                │
│  # 损失计算                                                                   │
│  loss = L1(pred_denorm, batch_y[:, -pred_len:, :])                           │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 完整推理流程

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                           推理流程 (forward_val_test)                          │
└────────────────────────────────────────────────────────────────────────────────┘

【输入】
  x_enc: (B, L=96, N=30)         # 测试集历史数据

    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 1: 条件编码                                                               │
│────────────────────────────────────────────────────────────────────────────────│
│  x_past = x_enc.permute(0, 2, 1)                # (B, N, 96)                  │
│  x_past_norm = RevIN_norm(x_past)               # (B, N, 96)                 │
│  x_past_flat = x_past_norm.reshape(B*N, 96)     # (B*N, 96)                  │
└────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 2: 多次采样循环 (sample_times=5)                                          │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  all_samples = []                                                             │
│                                                                                │
│  for sample_i in range(sample_times=5):                                       │
│  ┌─────────────────────────────────────────────────────────────────────────┐  │
│  │  2.1 初始化随机噪声                                                       │  │
│  │   x_T = randn(B*N, pred_len)                         # 纯噪声起点          │  │
│  └─────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌─────────────────────────────────────────────────────────────────────────┐  │
│  │  2.2 DPM-Solver 采样 (S=2 步)                                            │  │
│  │                                                                              │  │
│  │   for t in reversed(range(S)):                                             │  │
│  │   ┌────────────────────────────────────────────────────────────────────┐  │  │
│  │   │  # 噪声预测                                                          │  │  │
│  │   │  noise_pred = STFormerBone(x_t, t, x_past_flat)                     │  │  │
│  │   │  # 去噪一步                                                          │  │  │
│  │   │  x_{t-1} = dpm_solver_step(x_t, noise_pred, t)                      │  │  │
│  │   └────────────────────────────────────────────────────────────────────┘  │  │
│  │   最终: x_0 = 预测的干净序列                                              │  │
│  └─────────────────────────────────────────────────────────────────────────┘  │
│           │                                                                      │
│           ▼                                                                      │
│  ┌─────────────────────────────────────────────────────────────────────────┐  │
│  │  2.3 反归一化                                                           │  │
│  │   x_0_denorm = RevIN_denorm(x_0)  # (B, N, 12)                        │  │
│  │   all_samples.append(x_0_denorm)                                         │  │
│  └─────────────────────────────────────────────────────────────────────────┘  │
│  end for                                                                     │
└────────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│ Step 3: MoM 鲁棒聚合                                                           │
│────────────────────────────────────────────────────────────────────────────────│
│                                                                                │
│  # all_samples: (M=5, B, N, 12)                                               │
│  # 鲁棒中位数聚合                                                             │
│  result = rob_median_of_means(all_samples)  # (B, N, 12)                     │
│                                                                                │
│  result = result.permute(0, 2, 1)           # (B, 12, N)                     │
│                                                                                │
│  输出: result (B, 12, N)                                                       │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 4. 核心模块说明

### 4.1 STJointLayer (时空联合层)

```python
class STJointLayer(nn.Module):
    """
    时空联合层
    
    整合时序分支 + 空间分支 + 向量级门控
    
    输入: (B, N, P, d)
    输出: (B, N, P, d)
    """
```

**数学形式**:
```
gate = σ(W_g · Concat[H_T, H_S])
H_new = H + gate ⊗ H_T + (1-gate) ⊗ H_S
```

### 4.2 TemporalAttention (时序分支)

```python
class TemporalAttention(nn.Module):
    """
    时序注意力分支
    
    架构：Pre-LN → RotaryAttn → FFN → Residual
    
    特点：
    - 无因果掩码（纯扩散，注意力全局）
    - Pre-LN 结构（更稳定）
    - RotaryEmbedding（位置编码）
    """
```

### 4.3 SpatialPropagation (空间分支)

```python
class SpatialPropagation(nn.Module):
    """
    空间传播分支
    
    核心：D @ Q 操作（LWR 物理先验）
    
    D 矩阵物理意义：
    - D = I - S^T
    - S^T: 下游传播权重（上游客流流向）
    - D @ q: 上游 deficit（拥堵波沿拓扑边上行传播）
    """
```

## 6. 与 FormerBone 对比

| 特性 | FormerBone | STFormerBone |
|------|-----------|--------------|
| 时空处理 | 分离式 | 联合式 |
| 编码器结构 | T-Down/T-Mid/T-Up | 无 (纯联合) |
| Skip Connection | 有 | 无 |
| 因果掩码 | 有 | 无 |
| S-LWR 位置 | 末尾单次 | 每层执行 |
| T-Fusion 位置 | 末尾单次 | 每层执行 |
| 时间注入 | 拼接 | 加法广播 |

---

## 7. 核心优势

1. **时空耦合内生化**: 每层同时处理时空信息，避免信息断裂
2. **向量级门控**: 细粒度控制每维度特征来源
3. **架构简化**: 移除复杂的编解码器结构
4. **扩散友好**: 无因果掩码，适合扩散模型特性
